**New Features**

* Added Investor Portfolio position and group data for days and weeks held, week-to-date and month-to-date returns, annualized returns, and today's gain/loss percentage.
* Added previous-year income totals to processed position and group data.
* Added `WTD` and `MTD` position summary frames.
* Added the `opening.date` and `closing.date` fields to `PositionSchema`.

**Bug Fixes**

* Fixed portfolio processing to register forex conversions dynamically for position currencies outside the predefined currency list.
* Fixed position group ordering when positions create groups after initial portfolio processing.

**Configuration Changes**

* Replaced the Gulp-based test bundle flow with an esbuild.
