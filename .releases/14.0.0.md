**Breaking Changes**

**New Features**

* Added an optional parameter to `PositionContainer.getGroup` function which changes the return type to a `PositionGroup` instance.
* Added an optional parameter to `PositionContainer.getGroups` function which changes the return type to an array of `PositionGroup` instances.

**Technical Enhancements**

* Consolidated the `@barchart/portfolio-client-js` and `@barchart/portfolio-api-common` packages into a Lerna monorepo.
* Replaced the Gulp-based build workflow with package scripts and shared build tools.

**Other**

* Synchronized both package versions at `14.0.0`.
